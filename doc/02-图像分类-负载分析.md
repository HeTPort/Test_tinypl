# 图像分类（IC01）负载设计分析

## 设计目标与定位

该负载把一张固定尺寸彩色图像交给设备端量化模型，输出 10 类评分。仓库中的类别、张量形状、通用 TensorFlow Lite Micro 包装器和量化辅助函数清楚说明了接口设计；实际模型数组和完整设备端接线代码未提供。

```mermaid
flowchart LR
    A[图像样本 32 × 32 × 3] --> B[runner 读取二进制样本]
    B --> C[UART db 缓冲区 3072 B]
    C --> D[TFLM MicroModelRunner 输入张量]
    D --> E[量化模型 Invoke]
    E --> F[输出张量 / 反量化]
    F --> G[10 类评分 → Top-1 / AUC]
```

## 核心思路

1. **固定张量减少设备侧工作。** 输入常量为 32 列、32 行、3 通道，共 3072 个元素；`MAX_DB_INPUT_SIZE` 也设为 3072 字节。主机按文件读取字节并发送，仓库未显示设备端图像缩放、颜色变换或归一化，因此这些步骤应由数据准备阶段与模型训练约定。[模型设置](https://github.com/HeTPort/Test_tinypl/blob/2eefac5b64a957133cb6b997dfa3949a401a68c7/image_classification/ic_model_settings.h#L19-L37)、[设备接口](https://github.com/HeTPort/Test_tinypl/blob/2eefac5b64a957133cb6b997dfa3949a401a68c7/image_classification/submitter_implemented.h#L29-L57)
2. **将推理引擎封装为可替换组件。** `MicroModelRunner<inputT, outputT, numOps>` 持有模型、算子解析器、张量内存区和解释器；构造时分配张量，`SetInput()` 拷贝输入，`Invoke()` 执行，`GetOutput()` 提取输出。这是设备接入层的通用骨架，具体算子列表、内存区大小及模型实例化没有出现在本仓库。[TFLM 包装器](https://github.com/HeTPort/Test_tinypl/blob/2eefac5b64a957133cb6b997dfa3949a401a68c7/image_classification/tf_micro_model_runner.h#L16-L79)
3. **显式量化边界。** 辅助函数按 `scale`、`zero_point` 在 float 与 int8 之间转换，并对 int8 结果限幅。包装器也公开输入与输出张量的量化参数。模型数据头文件中的符号名为 `pretrainedResnet_quant_tflite`，可看出预期是量化 TFLite 模型；仅凭名称不能确认具体 ResNet 层次或部署性能。[量化函数](https://github.com/HeTPort/Test_tinypl/blob/2eefac5b64a957133cb6b997dfa3949a401a68c7/image_classification/quantization_helpers.h#L18-L39)、[模型符号](https://github.com/HeTPort/Test_tinypl/blob/2eefac5b64a957133cb6b997dfa3949a401a68c7/image_classification/ic_model_quant_data.h#L17-L22)

## 输出与评价

类别表列出 airplane、automobile、bird、cat、deer、dog、frog、horse、ship、truck。运行器使用最大评分的索引计算 Top-1，并尝试计算多类 one-vs-rest AUC；性能模式从设备时间戳计算吞吐量，能耗模式读功率采样。这里的评分归一化是简单除以总和，不等同于 softmax；若模型输出不是非负概率，AUC 的含义应另行核对。[类别表](https://github.com/HeTPort/Test_tinypl/blob/2eefac5b64a957133cb6b997dfa3949a401a68c7/image_classification/ic_model_settings.cc#L16-L21)、[汇总逻辑](https://github.com/HeTPort/Test_tinypl/blob/2eefac5b64a957133cb6b997dfa3949a401a68c7/runner/main.py#L255-L325)

## 可见边界

仓库没有该量化模型的数据定义，也没有完整 `th_load_tensor()`、`th_infer()`、`th_results()` 接线实现；所以这里能够确认的是负载协议、张量布局和推理封装，不能断言实际精度或硬件资源用量。
